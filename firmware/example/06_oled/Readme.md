# STM32H5-KIT OLED Display (SSD1306) Example

이 예제는 CLI 기반 시스템에 SSD1306 OLED 디스플레이 제어 기능을 추가한 예제입니다. 
터미널에서 입력한 문자를 실시간으로 OLED 화면에 출력하며, I2C 통신 속도에 따른 성능 차이를 비교할 수 있습니다.

---

## 개발 환경

- **MCU**: STM32H563-kit(Higenis)
- **IDE**: STM32CubeIDE
- **언어**: C
- **드라이버**: HAL Driver 기반

---

## 주요 특징

- **실시간 문자 출력**: 키보드 입력이 즉시 OLED에 표시됨
- **5×7 폰트 렌더링**: ASCII 32~126 문자 지원 (한글 미지원)
- **자동 줄바꿈**: 화면 끝에 도달 시 자동 개행
- **블로킹 모드**: OLED 테스트 중 CLI 명령어 수신 일시 중지
- **I2C 속도 비교**: Standard(100kHz) vs Fast(400kHz) 모드

---

## 사용 방법

### OLED 테스트 명령어

터미널(USART1)에서 다음 명령어를 입력하세요:

cli# oled test


입력 후:
1. 키보드로 입력한 문자가 실시간으로 OLED에 표시됩니다
2. 화면이 가득 차면 자동으로 초기화되고 맨 위부터 다시 출력됩니다
3. **Enter 키**를 누르면 OLED가 꺼지고 CLI 모드로 복귀합니다

### 전체 명령어 목록

| 명령어 | 인자 | 동작 설명 |
|--------|------|-----------|
| `help` | - | 등록된 모든 명령어 목록 출력 |
| `led` | `on` / `off` / `toggle` | LED 제어 |
| `uart6` | - | UART6으로 메시지 전송 |
| `uart10` | - | UART10으로 메시지 전송 |
| `rs232` | - | UART7(RS232)로 메시지 전송 |
| `rs485` | `1` / `2` | RS485-1 또는 RS485-2로 메시지 전송 |
| **`oled`** | **`test`** | **OLED 실시간 입력 모드** |
