# STM32H5-KIT FDCAN 통신 테스트 예제

이 예제는 CLI 기반 시스템에 **FDCAN 통신 테스트 기능**을 추가한 예제입니다.  
터미널에서 입력한 문자를 실시간으로 CAN 버스를 통해 전송하고 루프백 수신을 확인할 수 있습니다.

---

## 개발 환경

- **MCU**: STM32H563-kit(Higenis)
- **IDE**: STM32CubeIDE  
- **언어**: C
- **드라이버**: HAL Driver 기반

---

## 주요 특징

- **모드 간단 변경**: #define 되어있는 변수 하나로, loopback <-> normal 전환 가능
- **실시간 CAN 테스트**: 키보드 입력 → CAN TX → RX 즉시 확인 (폴링)
- **500Kbps Classic CAN**: 80MHz FDCAN 클럭 최적화 (샘플포인트 87.5%)
- **CAN1/CAN2 독립 테스트**: 채널별 개별 루프백 테스트
- **블로킹 모드**: CAN 테스트 중 CLI 명령어 수신 일시 중지

---

## 사용 방법

### CAN 테스트 명령어

터미널(USART1)에서 다음 명령어를 입력하세요:
cli# can test 1 # CAN1 루프백 테스트 시작
cli# can test 2 # CAN2 루프백 테스트 시작


입력 후:
1. 키보드로 입력한 문자가 CAN 버스로 전송됩니다 (ID: 0x123)
2. **루프백 모드**에서는 즉시 수신되어 화면에 출력됩니다
3. **Enter 키**를 누르면 CAN 종료 후 CLI 모드로 복귀합니다

### 전체 명령어 목록

| 명령어 | 인자 | 동작 설명 |
|--------|------|-----------|
| `help` | - | 등록된 모든 명령어 목록 출력 |
| `led` | `on` / `off` / `toggle` | LED 제어 |
| `uart6` | - | UART6으로 메시지 전송 |
| `uart10` | - | UART10으로 메시지 전송 |
| `rs232` | - | UART7(RS232)로 메시지 전송 |
| `rs485` | `1` / `2` | RS485-1 또는 RS485-2로 메시지 전송 |
| `oled` | `test` | OLED 실시간 입력 모드 |
| **`can`** | **`test 1~2`** | **CAN1/CAN2 루프백 테스트** |
